## Qué es

Un clúster de Kubernetes tiene un **API server** (6443), por el que pasa toda la administración, y
en cada nodo un **kubelet** (10250), el agente que arranca los contenedores y da acceso a sus logs
y a ejecutar comandos en ellos. Cada pod se identifica ante el API server con el token de su
**cuenta de servicio**, montado automáticamente dentro del contenedor.

## Qué buscar

- **Acceso anónimo** al kubelet o al API server.
- **Tokens de cuentas de servicio** dentro de los pods.
- **Permisos** de esas cuentas (crear pods, leer secrets).
